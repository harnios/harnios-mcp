# Dashboard

The Dashboard is the app's home page (`/`) — a single list of links to every other top-level page:
Files, Tools, External MCP Servers, Settings (connected apps, personal access tokens, test
messaging), and Schedules.

It requires signing in as the owner — visiting it while signed out redirects to the sign-in page
first. It doesn't show any live data of its own (no counts, no recent activity); it's purely a
starting point for finding the page you need.
